☕ AI Café for cafés

How a café owner would connect PayPal and what the café gets. ← Storefront · Agent Control Center
Honest scope. This page is a guided walkthrough. It does not connect a real PayPal merchant account: this deployment serves one merchant and is hard-wired to the PayPal Sandbox. There is no live-money onboarding in this prototype. The readiness checklist below is read live from this server; everything else is explanation.

1 · Setup path for a café owner

  1. Create a PayPal Business account
    The café owner’s own account is where money would land. Not done by this app.
  2. Create an app in the PayPal Developer Dashboard
    Start in Sandbox. You receive a client ID and secret and create a personal sandbox buyer for tests.
  3. Give the server its credentials
    Set PAYPAL_ENABLED, PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET. Secrets live only in server environment variables.
  4. Register the webhook
    Run npm run register-webhook so PayPal can notify the server; signatures are verified.
  5. Describe the café
    Menu, currency and limits come from a profile file (BUSINESS_PROFILE_PATH). Four example businesses ship with the repo.
  6. Protect the dashboard
    Set OPS_COPILOT_KEY; refunds then require the merchant key and a human approval.
  7. Test with the sandbox buyer
    Run npm run e2e:sandbox, approve on PayPal, watch the order turn PAID on the dashboard.

3 · What the café gets

Orders arrive preparedThe AI builds the cart from the real menu; the server fixes every price, so staff never see a wrong total.
Customers stay in controlSpending limits are enforced on the server and every payment needs the customer’s PayPal approval.
Live order boardAG Grid dashboard with order, payment and policy status. Filter, sort and export.
Refunds with a human in the loopA refund is proposed, then approved by the merchant. Nothing is refunded automatically.
Dispute evidenceA signed evidence package is prepared from the order record. The merchant submits it; the app never invents a PayPal outcome.
Group ordersSplit Bill: each person pays their own share on PayPal and the order closes when all shares are paid.
