Welcome to the unified knowledge base for your developers and AI agents!

APIMatic generates this portal and all included artifacts from your OpenAPI spec. Everything stays automatically in sync as your API evolves, so your API knowledge never goes stale.

## What's included

<Cards>

<Card title="Context Plugins">
Plugins for coding agents like Claude Code, Cursor, and GitHub Copilot so they can generate accurate, production-ready integration code.
</Card>

<Card title="SDKs" href="/sdks">
Typed, idiomatic client libraries with authentication built in, engineered for developers and AI agents alike.
</Card>

<Card title="API Reference">
An API reference with SDK code samples for each operation, and a live API playground to call the API.
</Card>

<Card title="Agent-Friendly Docs" href="/llms.txt" external>
Full Markdown documentation alongside `llms.txt` and `llms-full.txt` files, with one-click shortcuts to send any page to Claude, ChatGPT, or Cursor.
</Card>

</Cards>

## Make it yours

- Set your logo, favicon, colours, and header links in `src/apimatic.json`.
- Add Markdown pages to `src/content/`.
- Replace this page with your own introduction page.
